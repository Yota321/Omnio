# Manga Wrapped 2026

My year in manga, told as a retro scroll story. One HTML file, no frameworks, works offline.

Built from my AniList, Kitsu, MyAnimeList and Mihon libraries, merged so every manga counts once.

## Files

```
index.html
assets/
  P1.webp       cover for "Highest rated"
  P2.webp       cover for "Hidden gem"
  ambient.mp3   ambient sound
```

Missing assets are fine. The page falls back to a generated cover and a soft synth pad.

## Features

- Flip-clock loader, flat retro colors, dark and light mode
- Library totals, chapters read, yearly and monthly charts, score histogram
- Spotlights: highest rated, hidden gem, longest, fastest, slowest, newest
- Top creators, title word cloud, achievements, 47 facts
- Keyboard arrows, Calm mode, JSON export
